# TwitchAudioSync
Пример будет основан на Chrome
1. Загрузите все файлы и переместите в одну папку
2. Откройте "Расширения" в своём браузере
3. Включите режим разработчика и нажмите на кнопку "Загрузить распакованное расширение"
4. Откройте VOD и откройте расширение нажав на список всех расширений и выбрав "Twitch VOD Audio Sync"
5. В открывшемся окне добавьте файл с вашим Аудио

- Кнопка Паузы и Воспроизведения отвечает за Аудио, то есть включение выключения ТОЛЬКО Аудио.  
- Отклонение показывает насколько Аудио отстаёт или опережает VOD, контролируется вписанием времени или нажатием на кнопки. Можно сбросить нажав на кнопку  
- Кнопка Паузы - будет ли ставиться VOD на паузу между переключениями вкладок/окон  
- Кнопка Автокоррекции - корректирует VOD и Аудио для более точного звука
